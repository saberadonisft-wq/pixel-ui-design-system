# Codex repository guidance

- Always read `skills/pixel-ui-design-system/SKILL.md` before creating or changing UI.
- Always compose product UI from shared primitives in `packages/core` and `packages/react`.
- Never crop a reference image or use a screenshot as a background or assembled asset.
- Never hard-code a design-token value inside component or screen CSS; add or reuse a semantic token.
- Always verify responsive behavior at 320, 375, 414, and 768 CSS pixels.
- Always render and visually review the representative primitive and affected demos before finishing.
- Preserve semantic HTML, keyboard support, visible focus, and non-color state cues.
